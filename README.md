# Hotel Sales Power BI Dashboard

## Project Overview

This project presents an interactive Power BI dashboard developed to analyze hotel sales performance and revenue trends.

## Objectives

* Analyze total hotel sales and revenue.
* Monitor monthly revenue and daily sales trends.
* Identify popular food items.
* Analyze customer payment methods.
* Support data-driven business decisions.

## Key Features

* Total Sales Analysis
* Monthly Revenue Tracking
* Daily Sales Trend Analysis
* Food Item Performance
* Payment Method Analysis

## Tools and Technologies

* Microsoft Power BI
* Microsoft Excel

## Project File

The Power BI dashboard is available in the `.pbix` format.
